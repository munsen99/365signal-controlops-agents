# 02 — Retrieval allowlist

Retrieval is a new host module,
`controlops_research/src/controlops_research/research/retrieve.py`.
It does not call `fetch.py`. PR2 fetch follows redirects when PR1 accepts
the next public URL, which includes hosts outside this list.

## Allowed hosts

Exact host match, lower-cased, no userinfo, HTTPS only, port 443 or omitted:

```text
learn.microsoft.com
microsoft.com
www.microsoft.com
support.microsoft.com
techcommunity.microsoft.com
azure.microsoft.com
adoption.microsoft.com
```

## aka.ms

`aka.ms` may appear only as a redirect hop. The retriever inspects
`Location` and requests the next URL only when that URL’s host is on the
allowlist above. `aka.ms` is not the stored evidence URL. A hop that is
missing, not a valid URL, or off the allowlist stops that candidate. The
off-list target is not requested.

The hop list is stored on the candidate, starting with the seed or
discovery URL and including each URL that was actually requested.

## Capture

`max_bytes_per_source = 200_000`. `retrieve_timeout_s = 20`.
The stored object is the captured prefix only. `content_hash` is the SHA-256
of `evidence/<candidate_id>.bin`. The id is generated by ControlOps.

Extracted text comes from those stored bytes. HTML is reduced to visible
text inside the research package. `extract_visible_text` is not called,
because it applies a different size limit. Text is tail-truncated to
`max_select_chars_per_source = 12_000`. `truncated` is true when the HTTP
body was prefix-cut or the text was tail-cut.

A usable candidate has HTTP 200, a stored file, a matching hash, and
non-empty text. Other retrieval outcomes are recorded and skipped.
